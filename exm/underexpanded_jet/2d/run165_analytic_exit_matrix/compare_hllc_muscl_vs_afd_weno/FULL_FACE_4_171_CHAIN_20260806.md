# AFD–HLLC–WENO-Z5：face (4,171) 的完整非物理状态生成链

## 1. 空间排列与两套五点模板

问题面为 `face=(4,171), dir=1`，位于单元 `j=170` 与 `j=171` 之间：

```text

j168       j169       j170          face 171       j171       j172       j173
-22.499    -21.438    -20.377       -19.846        -19.315    -18.254    -17.193 mm
   o-----------o-----------o-------------|-------------o-----------o-----------o
   <----------------------------- u_x < 0 ------------------------------------

左状态五点： [j168, j169, j170, j171, j172]
```

代码对左状态调用 `right(sl)`。对右状态调用 `left(sr)`；`left` 会把输入反向，
所以右状态进入候选公式的有效顺序是
`[j173,j172,j171,j170,j169]`。

## 3. 逐点非线性声学变换

当前 AFD 路径对每个单元独立计算：

```text
w0      = rho * (1 - 1/gamma)
w_plus  = 0.5 * (p + sqrt(gamma*rho*p) * un)
w_minus = 0.5 * (p - sqrt(gamma*rho*p) * un)
w3      = ur
w4      = utheta = 0
w5      = gamma = 1.4
```

得到：

| j | w0 | w_plus | w_minus | w3=ur |
|---:|---:|---:|---:|---:|
|168|0.208626633|-30979.8591|65936.8625|92.992777|
|169|0.210327062|-34085.5840|61753.7048|110.164858|
|170|0.150560791|-29358.3769|43179.4384|143.671573|
|171|0.085348037|-17039.6010|21323.4826|158.614492|
|172|0.104359771|-18285.2759|28576.8568|156.649501|
|173|0.140726509|-28443.4835|41401.0235|149.765942|

注意：每个点使用不同的 `sqrt(gamma*rho*p)`，所以这不是把六点状态投影到一个
统一冻结的线性特征基。

## 4. WENO-Z5 候选和选择公式

对有效顺序 `s0...s4`：

```text
q0 = ( 3*s0 - 10*s1 + 15*s2) / 8
q1 = (  -s1 +  6*s2 +  3*s3) / 8
q2 = ( 3*s2 +  6*s3 -    s4) / 8
```

`beta0,beta1,beta2` 为 Jiang--Shu 三点光滑度指标；当前 WENO-Z 使用：

```text
tau = abs(beta0-beta2)
alpha_k = d_k * [1 + (tau/(beta_k+1e-40))^2]
d = (1,10,5)
omega_k = alpha_k / sum(alpha)
```

即当前指数已经是 `q=2`。

## 7. WENO 后的非线性逆变换

代码使用：

```text
p   = w_plus + w_minus
rho = w0 / (1-1/gamma)
un  = (w_plus-w_minus) / sqrt(gamma*rho*p)
```

左状态：

```text
pL = -23976.6361 + 32327.3830 = 8350.74689 Pa
rhoL = 0.408569057
sqrt(gamma*rhoL*pL) = 69.11295
unL = -56304.0190 / 69.11295 = -814.666733 m/s
urL = 153.821629 m/s
cL = 169.158546 m/s
```

右状态：

```text
pR = -21753.5178 + 21809.6579 = 56.140162 Pa  (>0, 因而通过当前检查)
rhoR = 0.307519075
sqrt(gamma*rhoR*pR) = 4.916283
unR = -43563.1757 / 4.916283 = -8860.998302 m/s
urR = 157.173603 m/s
cR = 15.986921 m/s
```

右状态内能仍为正，但极小：`e_int=456.396 J/kg`；动能为
`3.92710e7 J/kg`。因此总比能达到 `3.92715e7 J/kg`。当前检查只要求
`rho>0, p>0, finite`，所以该状态继续进入 HLLC。

## 8. HLLC 实际选择

波速估计为：

```text
SL = -8876.985223 m/s
SR =  -645.508187 m/s
```

因为 `SR<0`，所有估计波均向负 x 传播。HLLC 不进入星区，也不使用接触波
`Sstar`；它直接返回右重构状态的物理 Euler 通量：

```text
F_rho       = rhoR*unR                         = -2.7249260e3
F_momentumN = rhoR*unR^2 + pR                 =  2.4145621e7
F_momentumT = rhoR*unR*urR                    = -4.2828644e5
F_energy    = unR*(rhoR*E_R + pR)             = -1.0701230e11 W/m2
```

所以这一步不是 HLLC 星区计算错误；HLLC 忠实地放行了坏的超声速右状态。

## 9. 通量如何破坏 cell j171

该面是 cell `j171` 的低侧面。`dx=1.0612967e-3 m`，所以仅该面的能量 RHS
贡献为：

```text
F_energy/dx = -1.0083166e14 J/(m3 s)
```

完整 RHS2 为：

```text
rho RHS = -2.3788549e6
radial-momentum RHS = -3.7385392e8
axial-momentum RHS  =  2.2622951e10
energy RHS          = -1.0077425e14
```

能量 RHS 的 100.06% 来自这个异常共享面；其他面和 RZ 项只提供很小的反向
修正。相邻 cell `j170` 得到近似等大反号能量 RHS `+1.00699e14`，因此共享面
守恒，但交换量完全错误。

`dt=2e-7 s`。RK2 各状态为：

|状态|rho|rho*ur|rho*un|rhoE|rho*e_int|
|---|---:|---:|---:|---:|---:|
|`U^n`|0.325042|51.4016|-299.999|153353.1|10846.5|
|stage-1 FE `U1`|0.298718|47.3810|-270.746|137163.7|10709.7|
|第二 FE bracket `U1+dt*RHS2`|-0.177053|-27.3898|4253.845|-2.00177e7|已不可容许|
|最终 RK2 组合|0.0739947|12.0059|1976.923|-9.93217e6|**-3.63420e7**|

最终动能密度为 `2.64098e7 J/m3`，而总能量密度已经是负数，得到
`rho*e_int=-3.63420e7 J/m3`、`p=-1.45368e7 Pa`，状态检查于是终止计算。

## 10. 因果链总结

```text
六点 stencil 中一单元压力/密度谷 + 速度尖峰
  -> 每点不同的非线性声学变换
  -> w_plus 与 w_minus 独立判断三个 substencil
  -> w_minus 将 80.75% 权重给候选0，w_plus 却主要选择候选1
  -> 两个 O(2e4) 声学数相加只剩 p=56 Pa
  -> 非线性逆变换的 1/sqrt(p) 将速度放大到 -8861 m/s
  -> 状态仍满足 rho>0、p>0、finite，未被拒绝
  -> HLLC 判断 SR<0，直接返回坏右状态物理通量
  -> face CFL=1.673，能量通量比 MUSCL 大约 694 倍
  -> 第二 FE bracket 已负密度，RK2 组合后负内能/负压力
```
