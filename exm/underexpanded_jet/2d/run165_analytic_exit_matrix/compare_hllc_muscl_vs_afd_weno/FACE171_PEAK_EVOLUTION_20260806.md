# Face 171 前兆与移动峰值演化

## 结论

流场中的压力谷/Mach 峰不是固定在 `j171` 长期增长。它沿负 `x`（逆向喷流、
上游方向）依次经过 `j173 -> j172 -> j171`。但是使计算崩溃的 WENO 右面状态
`p_R=56.14 Pa, u_R=-8861 m/s` 并未随该结构长期移动；它只在最后一次
`RK stage-1 FE` 后突然形成。

分析区域为 `i=4, j=168...174`，网格间距为 `1.0612967 mm`。粗步 plotfile
时间间隔为 `0.4 us`，最后增加失败前的 `t=73.8 us` stage 状态。

## 危险候选何时形成

|时间 [us]|候选0配对 p [Pa]|候选0配对 un [m/s]|wminus 的 omega0|最终 WENO pR [Pa]|最终 WENO unR [m/s]|

|73.6|1341|-1903|0.263|6702|-866|
|73.8 stage-1 FE|26.88|-12007|0.807|56.14|-8861|

`73.6 us` 已有明确前兆：候选0的压力降到 `1.34 kPa`、速度达到
`-1903 m/s`，但完整 WENO 组合仍安全。随后仅 `0.2 us`，`wminus` 的候选0
权重从 `0.263` 跳至 `0.807`，异常面状态才真正出现。

最后半阶段中 `j171` 自身压力只下降 `1.3%`，Mach 反而从 `6.85` 降到
`6.49`。关键变化在邻点：`j170` 压力下降 `8.1%`，`j172` 压力上升
`10.2%`，使一单元谷两侧进一步变陡。对应 `wminus` 的 `beta0` 从
`1.60e8` 降到 `5.36e7`，而 `beta1` 从 `7.67e8` 升到 `9.71e8`；平方
WENO-Z 比值随即把候选0推到主导地位。

所以必须区分：

1. 物理 cell-average 峰/谷持续存在并向上游移动；
2. 灾难性的 reconstructed face peak 不是长期存在的移动峰，而是移动结构
   到达当前 stencil 后，在最后一个 RK 半阶段由非线性权重突变生成。

## 在整个喷流波系中的位置

喷口位于右侧 `x=+2.441 mm`，逆向喷流向负 `x` 流动。沿喷流从右向左观察，
当前阶段的主要结构依次为：

1. 喷口后的高压欠膨胀喷流和连续膨胀区，压力下降、Mach 上升；
2. 本文追踪的压力最低/Mach 最高转折区；
3. 向左的内部压缩区/桶形激波分支，压力重新升高、Mach 下降；
4. 轴向 terminal/Mach shock；
5. 更靠左的低速回流/停滞区和来流 bow/startup shock。

轴向逆喷流 `M=1` 位置从 `68 us` 的 `x=-22.3 mm` 移到 `73.6 us` 的
`x=-25.1 mm`；局部 Mach 峰同时从 `x=-17.2 mm` 移到 `-19.3 mm`。
两者间距保持约 `5--6 mm`。因此从左侧前缘波系向喷口方向数，该局部转折区
确实是最靠右/最后方的显著内部波动；若按流体从喷口向左的行进顺序描述，它
则是首先遇到的显著压缩起点。它右侧仍有连续膨胀场和剪切层，所以不宜称为
“右侧再无任何波”。

谷值不仅移动，也显著加深：`68 -> 73.6 us` 期间局部最低压力从
`10.15 kPa` 降至 `4.34 kPa`，局部最大 Mach 从 `4.24` 升至 `6.85`；相邻
压缩区压力峰保持约 `37--38 kPa`，峰谷比从约 `3.7` 增至 `8.6`。这时喷口
的 `100 us` smoothstep ramp 尚未完成，波系仍处于增长和向上游扩展阶段，
不是稳态 SRP 波系。
