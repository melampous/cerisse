# R-Z Full Euler MMS

The formal no-solid SSPRK(4,3) RZ-1 result is documented in
[`RZ1_REPORT_20260722.md`](RZ1_REPORT_20260722.md). Its machine-readable
acceptance record is generated by `verify_rz1.py`.

This case verifies the complete inviscid axisymmetric Euler path with a smooth,
time-dependent manufactured solution. It is deliberately independent of IBM,
AMR, viscosity, and shock-only stabilization.

The primitive manufactured fields are periodic in `z`. Density, pressure, and
axial velocity are even in `r`; radial velocity is odd and therefore satisfies
`u_r=0` at the axis. A user source is formed from

```text
S = dU/dt + (1/r) d(r F_r)/dr + dF_z/dz - G,
G_radial_momentum = p/r.
```

The implementation uses first-derivative automatic differentiation, so the
source is not a hand-expanded symbolic expression. Initial states, analytic
outer-boundary ghost states, manufactured sources, and analysis references are
all cylindrical finite-volume averages evaluated with fourth-order
Gauss-Legendre quadrature including the radial Jacobian.

Three tests are required:

1. `order_rk=0`: compare the complete semi-discrete RHS against the exact
   cylindrical average of `dU/dt`.
2. SSPRK(3,3): evolve to `t=0.02` and compare the conservative state against
   the exact time-dependent cell averages.
3. Repeat the semi-discrete test with only the manufactured pressure varying.
   This separates the pressure-flux/geometric-source pair from advection.

The intended production-independent R-Z settings are
`cns.rz_euler_annular_average=1`, `cns.rz_euler_point_flux=1`, and the
MMS-tested matching annular-pressure source
`cns.rz_euler_annular_pressure_consistency=1`. Every shock-only hybrid/filter and
every unrelated near-axis empirical treatment is explicitly disabled by the
matrix runner.

Both global volume-weighted convergence and first-ring/first-three-ring errors
are reported. The radial-momentum RHS must converge locally at second order in
the first three rings and in the global maximum norm; global volume-weighted
convergence alone is not an acceptance criterion because each fixed near-axis
ring has a vanishing volume fraction under refinement.

Run and verify a matrix with:

```bash
./run_matrix.sh ./main2d.gnu.MPI.ex ./inputs /path/to/new_result_root
python3 verify_matrix.py /path/to/new_result_root
```

The standard matrix uses `N=16,32,64,128,256` for the complete RHS, the
pressure-only RHS, and the SSPRK(3,3) evolution, for 15 cases total.

Additional solver overrides can be appended after the result root. They are
recorded in `GLOBAL_OVERRIDES.txt` and appended last to every solver command.
For example:

```bash
RUN_SERIAL=1 ./run_matrix.sh ./main2d.gnu.ex ./inputs \
  /path/to/new_deconvolution_result \
  cns.rz_euler_cell_average_deconvolution=1
```

For a sandbox without an MPI launcher, build with `USE_MPI=FALSE` and set
`RUN_SERIAL=1`. MPI remains the runner default.

## 2026-07-22 result

The MMS isolated two independent first-ring defects in the experimental R-Z
point-flux path:

1. Reconstructing annular pressure data as point data leaves a leading
   pressure-flux/source mismatch. For a regular quadratic pressure, the
   matching source correction is

   ```text
   (p[i+1] - 2*p[i] + p[i-1]) / (24*r[i]).
   ```

   Correcting only `i=0` made the axis value exact but merely moved the
   first-order maximum into rings 1 and 2. The implemented correction is
   therefore applied consistently over the smooth radial domain.

2. Direct `cons2prim` of cylindrical cell averages interprets unresolved
   radial kinetic-energy variance as pressure. For `u_r=a*r`, the exact
   weighted variance in an annulus centred at `r` is

   ```text
   Var(r) = dr^2/12 - dr^4/(144*r^2).
   ```

   The matching radial WENO state subtracts this unresolved kinetic energy
   from pressure and updates `p,T,c,e` together. The geometric source uses the
   same recovered pressure. A linear-`u_r` diagnostic changed from strict
   first-order axis errors `2.287e-7, 1.144e-7` at `N=128,256` to
   `1.739e-8, 2.175e-9`.

The accepted local serial matrix is
`preflight_matrix_fix_r4_serial/verification.json`. Its principal results are:

| check | result |
|---|---:|
| full-RHS radial-momentum axis orders | 2.822, 2.963, 2.974, 2.944 |
| full-RHS first-three-ring orders | 2.846, 2.978, 2.996, 2.998 |
| pressure-only radial-momentum max `Linf` | `3.60e-13` |
| minimum evolved density | `0.94004` |
| minimum evolved pressure | `0.90008` |
| all verifier gates | pass |

`cns.rz_euler_annular_pressure_consistency` is deliberately default-off and
fails closed if pressure split, near-axis pressure alternatives, a point-flux
shock gate, or either consistent-shock hybrid is active. This smooth-MMS result
does not authorize enabling it in an SRP shock calculation; a separately
gated discontinuous-flow formulation and shock regression are still required.

### Radial conservative-state deconvolution A/B

An independently added opt-in path,
`cns.rz_euler_cell_average_deconvolution=1`, was audited against the same
15-case matrix. It fits a quadratic to three conservative annular averages
using the exact cylindrical moments and evaluates that polynomial at the
radial cell centre before `cons2prims`. The moment map exactly reproduces
`1`, `r`, and `r^2`. It is more general than the ideal-gas-specific unresolved
radial-kinetic-energy correction, but it is currently radial-only and uses
unlimited quadratic weights.

The path requires the ungated annular-average, point-flux, and
pressure-consistency options. It aborts for IBM/EB builds and remains off by
default. The accepted A/B result is
`preflight_matrix_deconv_r1_serial/verification.json`:

| check | pressure consistency | radial deconvolution |
|---|---:|---:|
| full-RHS axis orders | 2.822, 2.963, 2.974, 2.944 | 2.729, 2.805, 2.404, 2.258 |
| first-three-ring orders | 2.846, 2.978, 2.996, 2.998 | 2.844, 2.975, 2.993, 2.986 |
| finest-grid axis `Linf` | `6.06e-9` | `1.67e-8` |
| pressure-only max `Linf` | `3.60e-13` | `4.04e-13` |
| SSPRK evolution and positivity gates | pass | pass |

The deconvolution therefore removes the first-order axis defect, but this MMS
does not show an accuracy advantage over the narrower pressure-consistency
path. It is retained as a default-off research alternative, not selected as
the SRP production treatment. A discontinuity-preserving nonlinear limiter and
shock A/B are prerequisites before considering it for a Mach disk.

with the r2 MPI bundle. All 15 MPI-rank-1 cases completed between
