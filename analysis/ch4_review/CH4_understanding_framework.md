Three candidate outlines, sketch level. Each is internally consistent; they differ in how they resolve tensions #1–#2. **The author decides.**

### Direction A — Minimal repair: keep the 7-section skeleton, fix the seams

- Resolve the identity mismatch *by paperwork*: either rename folder/label to match the Euler title, or add one explicit paragraph in 01 stating that AMR/FSI/viscous extensions exist in the code but are deliberately outside this chapter's certified claim (with one sentence on where each will be evidenced).

- 03: compress SSPRK(4,3) to the four stages + audit deltas with `\ref` to Ch2; add the missing "why positivity lives here" bridge; one no-cut-cell statement, not five chapter-wide.
- 05: fix or explain the gate ordering; open with the *complete* frozen-family list (matching AGENTS.md); add a closing synthesis paragraph; move bare numbers into tables.
- 06/07: demote 07 to a half-page recap that only cross-references 06, or fold 07's claim-boundary paragraph into 06 and delete the rest.
- Global: wire the ~10 dangling references; pin one term each for ghost-state, surface-e2, NSCBC, grid phases; define "owned".

**Rationale:** the chapter's ordering (lit → formulation → integration → observables → verification → capability → summary) is fundamentally sound and the verification content is strong; most tensions are seam-level. **Cost:** low — pure editing, no new runs, no new content, no label churn beyond what's free. **Does not solve:** #2 (viscous/AMR/RZ evidence homelessness) and the missing FSI demo.

### Direction B — Two-part restructure: "Method" / "Evidence", plus an explicit extensions bridge

- **Part I — Method:** (i) slimmed literature + positioning (current 01 minus preview); (ii) formulation (02, with consolidated scope statement and blend-factor forms given or routed); (iii) integration, *reduced to IBM deltas* over Ch2 (stage-local refresh, WENO masking, crossing-face argument) with positivity + SSPRK(4,3) either as its own short section or kept as a clearly-bridged subsection.

- **New short closing section — "Uncertified extensions and route to application":** 1–2 pages acknowledging what exists beyond the certified core (NS no-slip closure + its MMS numbers, AMR audit infrastructure, RZ annular machinery, sharp-feature regularization, FSI demo capability), explicitly labelled *not certified*, hosting the supervisor-agreed FSI demo, and absorbing 06's six-step route + 07's forward bridge. This one section resolves #1, gives Ch5/6 concrete anchors, and honors the folder name without inflating the certified claim.

**Rationale:** matches the chapter's real logical shape (a certified core plus a fenced frontier), fixes #1/#2/#6/#8 structurally instead of cosmetically, and turns the negative-space table from a wall into a doorway. **Cost:** medium — resectioning and label churn (currently free — no external refs into `gpibm:*`), moderate new prose for the extensions section (the evidence already exists in `ibm_noslip_pressure_compatibility_20260727.md` etc.), but requires the uncommitted code truth to be stable enough to describe, and requires deciding what the FSI demo actually shows.
