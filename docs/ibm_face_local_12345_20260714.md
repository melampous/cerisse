# IBM Face-Local Follow-Up: Steps 1--5

Date: 2026-07-14

## Scope and conclusion

This work closes the five requested follow-ups for the stationary,
single-species ideal-gas GPIBM path:

1. map face-local WLS fallbacks in space and time;
2. construct an admissibility-preserving WLS limiter;
3. replace the unconditional near-wall MUSCL shell by marker-safe shifted
   same-side WENO-Z5/TENO5 where the stencil permits it;
4. run a smooth curved-wall Euler IBM MMS order test; and
5. verify distributed face ownership and a mass/momentum/total-energy budget.

The important qualification is that these steps do not make the experimental
direct face-state closure a production second-order IBM.  The established
production second-order result still belongs to the legacy GP reconstruction.
The direct face-state path fixes the 2-D Prandtl--Meyer corner pressure defect,
but it fails the smooth-wall MMS convergence gate and remains opt-in.

## 1. Per-face fallback map

The runtime audit now accumulates, for every Cartesian crossing-face copy:

- Cartesian face id, direction, fluid side, MPI rank and local FAB;
- first-hit geometry/element and physical hit point;
- support-anchor attempt and distance;
- final face/reflected polynomial orders and condition numbers;
- sample, WLS, scaled-WLS, metadata/weight/state-fallback, HLLC, HLLE and fatal
  counts;
- minimum limiter factor and maximum fluid-side jump; and
- the unique conservation-accounting owner flag.

The output is enabled by `ib.face_local_runtime_csv=<prefix>`.  It is
initialization metadata plus cumulative counters, so it does not add file I/O
to every Runge--Kutta stage.

The map changed the diagnosis.  In the earlier `N=180` PM experiment that
accepted scaled WLS states, 41 faces were affected over a broad ramp interval
(`x=3.14--9.36`, `y=-3.04---0.78`); the problem was not confined to the
geometric corner.  A deterministic support-anchor search was therefore added.
It preserves an initially valid linear/quadratic fit, searches outward only to
rescue constant or invalid fits, and caps a rescued fit at linear order.  This
prevents a search for more points from silently upgrading a low-quality fit.

In the final `N=180` PM run, 237 of 239 crossing faces used WLS per stage; two
static metadata failures used the adjacent fluid state, with zero dynamic
state/weight failures, zero HLLE selections and zero fatal states.  The smooth
curved-wall runtime audit used WLS on every sampled crossing face.

## 2. Admissibility-preserving WLS scaling

For a candidate face state and its reflected target, the implementation forms
one common linear scaling

```text
W(theta) = W_adjacent + theta * (W_WLS - W_adjacent),  0 <= theta <= 1.
```

Density, pressure, gamma and every velocity component use the same `theta` at
both targets.  Analytic lower bounds enforce buffered density, pressure and
gamma constraints; a 48-iteration bisection handles the remaining nonlinear
EOS/internal-energy admissibility test.  Sound speed and conservative total
energy are rebuilt after scaling.  Per-component clipping is not used.

This is a valid reconstruction-state limiter, but it is not a conservative
cell-average positivity limiter.  That distinction was observed directly:
accepting the scaled states in the `N=180` PM run remained locally admissible
at each Riemann solve but eventually failed the multidimensional update at
`t=2.972045816`.  The failure occurred downstream near `x=8.4`, not at the
corner.  Consequently:

```text
cns.afd_ibm_accept_scaled_wls = 0  # production default
```

The code computes and audits `theta`, then uses the adjacent first-order fluid
state whenever scaling was required.  Enabling acceptance is experimental
until a conservative shared-face positivity flux limiter is implemented.

## 3. Shifted same-side WENO/TENO shell

For a fluid/fluid face whose nominal AFD stencil intersects the solid, the
operator searches for a contiguous five-cell block on the fluid side.  It
reconstructs complete characteristic traces at the original Cartesian face,
checks smoothness, converts back to one thermodynamically consistent primitive
state per side, checks component-wise bounds, and calls the same checked
HLLC-to-HLLE solver used by the crossing closure.

The translated polynomial formulas reproduce degree-four data to roundoff.
Exhaustive target/moment tests pass for WENO-Z5 and TENO5.  The extreme
translations require a negative optimal linear weight.  Although a signed
WENO split is implemented and passes polynomial tests, PM runs showed that
enabling those extreme closures along the staircase is unstable.  Production
therefore enables fifth order only for the two positive-weight translations.
Unavailable, nonsmooth or unbounded traces use the adjacent real-fluid states.
No solid primitive is read.

This is a hybrid shell, not an unconditional fifth-order wall operator.  At the
last `N=180` PM stage, 175 of 478 shell faces used shifted fifth-order traces,
240 had no stable positive-weight translation, and 63 failed the boundedness
test.  All 478 still produced an admissible HLLC flux; HLLE and LLF counts were
zero.

The final PM co-refinement sequence is:

| Nx | angle error [deg] | Mach error [%] | p2/p1 error [%] | plateau p L1/L2 [%] | minimum p error [%] |
|---:|---:|---:|---:|---:|---:|
| 80  | -0.003654 | +0.103 | -0.025 | 0.078 / 0.125 | -0.232 |
| 120 | -0.000665 | +0.023 | -0.005 | 0.047 / 0.068 | -0.137 |
| 180 | +0.000242 | -0.002 | -0.001 | 0.030 / 0.044 | -0.132 |

No grid has a plateau cell more than 5% below the PM pressure.  The global
pressure L1 orders are `0.993, 0.996`; L2 orders are `0.807, 0.822`.  Excluding
a fixed `r=0.5` corner neighbourhood gives L1 `1.004, 1.002` and L2
`0.859, 0.874`.  These rates are consistent with a field containing a vertex
and expansion-fan head/tail; they are not a formal smooth-wall order result.

## 4. Smooth-wall Euler MMS

The fixed-time curved-wall sequence uses a 4,096-segment circle, analytic
curvature pressure compatibility, `iorder=eorder=eorder_surf=2`, `alpha=1`,
one ghost layer, AFD-HLLC-TENO5, and `N=32/48/64`.

The direct face-state closure fails this gate.  Its all-fluid fitted orders are
near zero or negative after the `N=64` error rebounds; the `t=0` RHS residual
also remains only approximately order `0.5`.  Support-anchor rescue changes
the failure mode but does not restore consistency.  It is therefore not a
production replacement for the GP closure.

The same test with the legacy GP-IBM path gives:

| Region | rho | u | v | p | T |
|---|---:|---:|---:|---:|---:|
| all fluid, fitted L2 order | 2.25 | 2.29 | 2.28 | 2.27 | 2.23 |
| first fluid shell, fitted L2 order | 1.45 | 2.02 | 2.01 | 1.75 | 1.58 |

Thus the present stationary smooth-wall IBM supports a global second-order
claim for the tested Euler-slip problem.  It does not support a pointwise
second-order claim for every variable in the first cell layer, and it does not
support a fifth-order immersed-boundary claim.  The all-fluid AFD operator
remains fifth order away from the wall.

## 5. Unique ownership and five-equation budget

The conservation diagnostic now integrates the canonical vector

```text
Q = (rho, rho*u, rho*v, rho*w, rho*E)
```

over valid fluid cells, excluding IBM solid cells and coarse cells covered by
finer levels.  It stores the actual combined Euler-plus-diffusive face flux
before divergence and accumulates it with the final RK quadrature weight.
Each Cartesian fluid/solid face is counted from its unique adjacent valid
fluid cell.  The uniform-grid identity is

```text
d/dt integral_fluid(Q) dV + Phi_outer + Phi_IBM = 0.
```

The old 51 CSV columns are unchanged; mass, energy, interface fluxes and direct
residuals are appended.  Old CSV files remain readable.  On AMR, composite
state, regrid-remap and outer/reflux accounting are available, but direct
fluid/solid interface residuals are deliberately `NaN` with
`interface_conservation_valid=0` until a composite AMR interface owner is
implemented.

OpenMPI `np=1/2/4` runs used four FABs on the same `32 x 32` curved-wall case.
All runs found 48 active faces and exactly 48 accounting owners, with no
duplicate owner group.  The `np=1/2/4` final plotfiles agree exactly.  Maximum
relative direct residuals were:

| Run | mass | momentum | total energy |
|---|---:|---:|---:|
| MPI np=1 | 3.17e-10 | 5.07e-10 | 5.40e-11 |
| MPI np=2 | 2.50e-10 | 5.07e-10 | 8.28e-11 |
| MPI np=4 | 2.50e-10 | 5.09e-10 | 8.28e-11 |
| CUDA sm_89 | 6.14e-11 | 5.93e-11 | 4.02e-11 |

The CUDA run used the complete `sm_89` build with cross-execution-space calls
treated as errors.  Relative CPU/GPU plotfile differences are at most
`2.88e-14`; the largest absolute total-energy difference is `1.46e-9`.

The startup surface-traction/control-volume mismatch is approximately 64% and
is intentionally not called a force validation pass.  The near-roundoff
five-equation residual proves discrete bookkeeping and unique flux accounting;
it does not prove that the reconstructed geometric VTP traction equals the
Cartesian interface momentum transfer.  That physical mismatch must be tested
on a resolved steady sequence.

## Production status

- **Production evidence:** legacy GP-IBM global second order for the tested
  smooth Euler-slip MMS; unique uniform-grid five-equation conservation
  accounting; CPU/MPI/CUDA consistency.
- **Useful opt-in research path:** direct first-hit face-state HLLC closure and
  positive-weight shifted shell.  It gives an excellent PM pressure trace but
  fails smooth-wall formal convergence.
- **Implemented but default-off:** acceptance of scaled WLS states.
- **Still required:** a conservative cell-update positivity limiter; a
  consistent second-order direct face-state wall closure; direct AMR
  fluid/solid interface ownership; resolved steady surface-traction/CV force
  closure; and equivalent smooth-wall NS no-slip/thermal MMS gates.
